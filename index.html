VaultPanel

A web control panel for Linux servers. Latest version: 0.4.0

Install

On a fresh Ubuntu 22.04, 24.04 or 26.04, or Debian 12 or 13 server, as root:

apt update && apt -y upgrade && apt -y install curl wget sudo
curl -sS https://installer.vaultpanel.net/v2/install.sh -o install.sh; \
echo "37779be96c4732cf4fdf5a39a6786b1de60f5361c44bcce4a0f2baaf26495d57 install.sh" | \
sha256sum -c && sudo DB_ENGINE=MARIADB_12.3 bash install.sh

DB_ENGINE chooses the MariaDB version for websites and apps; the versions each system offers are listed on GitHub.

Update

sudo vaultpanel update
